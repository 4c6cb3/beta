# 暗記アプリ　memoly (beta ver.)

memory(覚える)とlight(軽い)が名前の由来な、AIが作った暗記アプリ。
https://4c6cb3.github.io/beta/

## ウェブアプリ化しての使用がおすすめです
### iOSの場合
①Safariでウェブサイトに移動する

②･･･をタップして「共有をタップ」

③リストを下にスクロールし、「ホーム画面に追加」をタップ

### Androidの場合

①Chromeでウェブサイトを開き、メニューボタン（縦の3点）をタップ

②「アプリに追加」を選択、名前を入力して「追加」

## ざっくりした使い方
① オプションより、学習モードを選択する

② .csvファイルを取り込む、または自分で新規デッキを作ることで、「学習を開始」をタップする

③ 画面タップで答えを表示し、自分で暗記できていたかを評価する（必要に応じて検索ボタンをタップ）

④ これを繰り返してめちゃくちゃmemolyしてね

## ver.1.3.0より追加された長押し機能のざっくりした説明
- 「あと少しだけあればわかるのに…！」という学習に最適です。
- 学習モードがノーマルモードの時は、答えが1文字ずつ表示されるよ
- 学習モードが読み上げ風モードの時は、①問題文がまだ全文表示されていないときは、問題文が続きから1文字ずつ表示されるよ②問題文が全文表示されているときは、答えが1文字ずつ表示されるよ
